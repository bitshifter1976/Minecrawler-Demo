# Minecrawler Demo

**Dig in. Clear the mine. Survive the enemies.**

Minecrawler is a retro-inspired arcade mining game for **Windows** and **Android**. Guide your miner through increasingly challenging levels, collect coal, blast obstacles, and make it safely to the exit. Watch out for enemy bosses and their hazards!

This free demo includes the **first 5 levels** of Minecrawler.

## Download

Get the latest demo from the **[GitHub Releases](../../releases/latest)** page.

| Platform | Download | How to play |
| --- | --- | --- |
| Windows | `Minecrawler_Demo_vX.Y.Z.zip` | Extract the entire ZIP, then launch `Minecrawler.exe` (or the included game executable). Keep the accompanying files together. |
| Android | `Minecrawler_Demo_vX.Y.Z.apk` | Download the APK to your Android device and install it. Android may ask you to allow installation from this source. |

## Features

- **5 playable levels** in the demo
- Arcade-style mining and exploration
- Coal collection and destructible rocks
- Enemy encounters and boss battles
- Weapon upgrades
- Keyboard/mouse support on Windows and touch controls on Android

## Demo vs. Full Game

| Feature | Demo | Full game |
| --- | --- | --- |
| Campaign levels | 1–5 | 1–100 |
| Endless mode | No | Yes |
| Windows and Android | Yes | Yes |

The demo ends after level 5. The full game continues through the complete campaign and unlocks **Endless Mode**.
